# 智慧农业平台演示页面说明

本目录包含两个单文件 HTML 演示页面，用于**业务演示**。两个页面均无任何外部依赖（无 CDN、外链 JS/CSS/图片、字体走系统），双击即可在浏览器离线打开，顶栏导航可互相跳转。

| 文件                                   | 页面         | 使用角色                              |
| ------------------------------------ | ---------- | --------------------------------- |
| [`./stock.html`](农资管理.html) | 农资管理（出入库）  | 库管员（PC 端录入/入库）＋ 员工（小程序支取，页面展示其结果） |
| [`./planting_records.html`](种植档案.html)         | 种植档案（自动归档） | 归档后只读查看，面向全场角色                    |

---

## 一、农资管理页（[./stock.html](农资管理-出入库演示.html)）

### 1. 业务背景

- **库管员**在 PC 端录入农资、执行入库；
- **员工**在小程序端发起支取（每次支取必须选择地块，**可选多个地块**）；
- 本页面负责农资台账与出入库流水展示，支取数据来源于小程序。

### 2. 平台汇总卡片（页面顶部）

展示全平台口径：农资品类数、累计入库次数、累计支取次数、累计入库金额、累计支取金额、当前库存价值（Σ 库存量×单价）。

### 3. 搜索功能

添加按照农资编码搜索。

### 3. 物资列表

- 农资列表无变化，在操作中添加“出入库记录”
- **操作**：
  - 出入库记录：打开弹窗。

### 4. 出入库记录（核心）

- **统计卡片（全量口径，不随日期筛选变化）**：总入库 / 总支取 / 当前库存 / 入库总金额 / 支取总金额。
- **日期区间查询（只筛下方明细）**：默认**本年度 1月1日 ~ 12月31日**（按运行时年份动态生成）；重置恢复默认；起止填反会被拦截提示；无数据时空态提示。
- **明细列表**：按时间**降序**（最新在最上）；折叠态即显示 类型徽标、支取人、时间、数量×单价、金额（2位小数）；点击展开显示农事描述，该记录由小程序记录农事处理时产生。
- **支取地块分摊表（核心业务规则）**：
  - 展开支取记录后显示其选择的地块明细：地块名称（含**作物标签**：小麦/玉米）、亩数、亩数占比、分摊支取数量、分摊支取金额；
  - **分摊规则**：`该地块分摊数量 = 支取总数量 × 该地块亩数 ÷ 所选地块总亩数`，金额 = 分摊数量 × 单价；
  - 因地块较多，表格**竖向滚动**，表头吸顶、合计行吸底，长地块名自动换行。

## 二、种植档案页（[./planting_records.html](种植档案演示.html)）

### 1. 业务背景与归档规则

- 种植批次状态变为「**种植结束**」后，系统**自动生成档案**（无需人工创建），编号规则 `农场编号-年度-流水号`；
- 档案**固化**该批次的农艺方案执行过程与投入成本，**只读、可追溯**；
- 同一地块多次种植（复种）会生成多个批次档案。

### 2. 汇总卡片（页面顶部）

| 指标      | 口径                                   |
| ------- | ------------------------------------ |
| 已归档种植批次 | 档案条数（一次完整种植 = 1 个批次）                 |
| 归档总面积   | 各批次面积**直接相加**（复种的地块会被重复计入，是"累计种植面积"） |
| 涉及作物    | 批次涉及的作物去重数                           |
| 覆盖地块    | 批次涉及的地块按名称**去重**后的块数                 |
| 归档总投入成本 | 各批次投入成本之和                            |
| 综合亩均成本  | 总投入 ÷ 归档总面积                          |

> 归档批次 ≥ 覆盖地块：每块地只种过一次时两者相等；有复种时批次多于覆盖地块。

### 3. 档案列表

- **列**：档案编号 ｜ 地块（名称前带**地块形状图标**——青框渐变绿多边形，模拟地块轮廓，不同档案形状不同）｜ 种植信息（作物-品种标签）｜ 农艺方案 ｜ 面积 ｜ 种植时间 ｜ 结束时间 ｜ 生长周期(天) ｜ 农事完成度(x/y) ｜ 总投入成本 ｜ 亩均成本 ｜ 操作。
- **筛选**：种植物 ＋ 地块 ＋ 归档年度 ＋ 关键词（编码/方案/品种/地块模糊匹配）。
- 点击档案编号或"投入分析"打开详情抽屉。

### 4. 档案详情抽屉

顶部为档案头卡片：地块名(面积)、作物-品种、种植日期、种植方案、位置、结束时间（含生长周期天数与经手人）。下方两个 Tab：

#### Tab 1 农艺方案

- 复用地块管理页面-农艺方案；

#### Tab 2 投入分析

- 复用地块管理页面投入分析。
