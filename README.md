# 智慧农业平台演示页面说明

本目录包含两个单文件 HTML 演示页面，用于**业务演示**。两个页面均无任何外部依赖（无 CDN、外链 JS/CSS/图片、字体走系统），双击即可在浏览器离线打开，顶栏导航可互相跳转。

| 文件                                   | 页面         | 使用角色                              |
| ------------------------------------ | ---------- | --------------------------------- |
| [`stock.html`](农资管理.html) | 农资管理（出入库）  | 库管员（PC 端录入/入库）＋ 员工（小程序支取，页面展示其结果） |
| [`planting_records.html`](种植档案.html)         | 种植档案（自动归档） | 归档后只读查看，面向全场角色                    |

---

## 一、农资管理页（[stock.html](农资管理-出入库演示.html)）

### 1. 业务背景

- **库管员**在 PC 端录入农资、执行入库；
- **员工**在小程序端发起支取（每次支取必须选择地块，**可选多个地块**）；
- 本页面负责农资台账与出入库流水展示，支取数据来源于小程序。

### 2. 平台汇总卡片（页面顶部）

展示全平台口径：农资品类数、累计入库（次数/数量）、累计支取（次数/数量）、累计入库金额、累计支取金额、当前库存价值（Σ 库存量×单价）。

### 3. 物资列表

- **列**：图片 ｜ 名称 ｜ 农资编码 ｜ 农资类型 ｜ 规格 ｜ 单价(元) ｜ **入库量** ｜ **出库量** ｜ 库存量 ｜ 备注 ｜ 操作。
- 入库量/出库量 = 该物资全部出入库记录求和，与抽屉统计同源；库存量满足 **入库量 − 出库量 = 库存量**。
- **筛选**：类型（下拉）＋ 名称（模糊）＋ **农资编码（模糊、忽略大小写，如输入 `jm` 可搜到 `JM-22`）**，支持回车查询、一键重置。
- **操作**：
  - 新增：录入新农资；
  - 添加库存：生成一条**入库记录**（时间取实时），库存量、入库量、统计卡片实时联动；
  - 删除：删除该物资；
  - 出入库记录：打开右侧抽屉。

### 4. 出入库记录抽屉（核心）

- **统计卡片（全量口径，不随日期筛选变化）**：总入库 / 总支取 / 当前库存 / 入库总金额 / 支取总金额。
- **日期区间查询（只筛下方明细）**：默认**本年度 1月1日 ~ 12月31日**（按运行时年份动态生成）；重置恢复默认；起止填反会被拦截提示；无数据时空态提示。
- **明细列表**：按时间**降序**（最新在最上）；折叠态即显示 类型徽标、经手人、时间、数量×单价、金额；点击展开显示农事描述。
- **支取地块分摊表（核心业务规则）**：
  - 展开支取记录后显示其选择的地块明细：地块名称（含**作物标签**：小麦/玉米）、亩数、亩数占比、分摊支取数量、分摊支取金额，以及**合计行**；
  - **分摊规则**：`该地块分摊数量 = 支取总数量 × 该地块亩数 ÷ 所选地块总亩数`，金额 = 分摊数量 × 单价；
  - **末地块兜底**：最后一个地块用"总量 − 已分摊"计算，保证各地块分摊之和与支取总量**严格相等**（避免四舍五入误差）；
  - 地块较多时表格**横竖双向滚动**，表头吸顶、合计行吸底，长地块名自动换行。

### 5. 演示数据说明

数据为页面内置的演示数据（物资1、雨小麦、尿素、济麦-22 等），其中雨小麦有一条 **10 个地块**的支取记录，专门用于演示分摊表的滚动效果；删除或修改数据不会持久化，刷新即恢复。

## 二、种植档案页（[planting_records.html](种植档案演示.html)）

### 1. 业务背景与归档规则

- 种植批次状态变为「**种植结束**」后，系统**自动生成档案**（无需人工创建），编号规则 `ZDA-年度-流水号`；
- 档案**固化**该批次的农艺方案执行过程与投入成本，**只读、可追溯**；
- 同一地块多次种植（复种）会生成多个批次档案。

### 2. 汇总卡片（页面顶部）

| 指标      | 口径                                   |
| ------- | ------------------------------------ |
| 已归档种植批次 | 档案条数（一次完整种植 = 1 个批次）                 |
| 归档总面积   | 各批次面积**直接相加**（复种的地块会被重复计入，是"累计种植面积"） |
| 涉及作物    | 批次涉及的作物去重数                           |
| 覆盖地块    | 批次涉及的地块按名称**去重**后的块数                 |
| 归档总投入成本 | 各批次投入成本之和                            |
| 综合亩均成本  | 总投入 ÷ 归档总面积                          |

> 归档批次 ≥ 覆盖地块：每块地只种过一次时两者相等；有复种时批次多于覆盖地块。

### 3. 档案列表

- **列**：档案编号 ｜ 地块（名称前带**地块形状图标**——青框渐变绿多边形，模拟地块轮廓，不同档案形状不同）｜ 种植信息（作物-品种标签）｜ 农艺方案 ｜ 面积 ｜ 种植时间 ｜ 结束时间 ｜ 生长周期(天) ｜ 农事完成度(x/y) ｜ 总投入成本 ｜ 亩均成本 ｜ 操作。
- **筛选**：种植物 ＋ 地块 ＋ 归档年度 ＋ 关键词（编码/方案/品种/地块模糊匹配）。
- 点击档案编号或"投入分析"打开详情抽屉。

### 4. 档案详情抽屉

顶部为档案头卡片：地块名(面积)、作物-品种、种植日期、种植方案、位置、结束时间（含生长周期天数与经手人）。下方两个 Tab：

#### Tab 1 农艺方案

- 顶部**农事完成度进度条**（x/y 环节完成）；
- 每个农事环节一张卡片：已完成/未完成徽标、环节名、日期区间、分项成本明细（其他/农资/人工/农机，各显示"共¥X ≈¥Y/亩"）及环节小计；
- **未执行环节**：红色徽标、标注"该环节未执行，无成本发生"（演示数据"东汀沟"的"一喷三防"即此场景）；
- 点击环节卡片弹出**农事详情**：审核状态、农事编号、方案来源、农事类型、农事时间、处理地块（chips）、农事描述、图片、所用成本。

#### Tab 2 投入分析

- 头部一行：`当前投入共计：¥X ≈¥Y/亩`；
- **环形图**：中心显示总计金额与"共 计"，每个成本分类一段扇区，外部标签（分类名＋金额＋占比%）带彩色引导线，扇区按金额降序、从顶部顺时针排布；
- **图例**：农资(红) / 人工服务(绿) / 农机服务(橙) / 其他服务(青)；
- **分项表格**：分项 ｜ 总计/元 ｜ 亩均/元 ｜ 占比/%，分项名用对应颜色浅底标签；
- 下方保留"按农事环节"条形图（未执行环节灰色并标注）。

### 5. 演示数据说明

内置 6 个档案（含复种场景可自行扩充），成本数字参考真实平台截图（如播种 ¥4,570.71 ≈ ¥4.12/亩）。

## 三、技术说明（两个页面通用）

- **单文件自包含**：全部 HTML/CSS/JS 在一个 `.html` 内，无构建、无网络请求，任何现代浏览器直接打开。
- **数据内置**：演示数据写在页面 `<script>` 的数组里（农资页为 `supplies`，种植档案页为 `archives`），修改数组即改数据，刷新页面恢复初始状态（无持久化）。
- **视觉规范**：主题绿 `#00a870`，金额统一两位小数（`¥100.00`），中文界面，微软雅黑/PingFang。
- **对接真实后端**：两个页面的渲染函数（农资页 `renderTable` / `renderDrawer`，种植档案页 `renderStats` / `renderTable` / `renderDrawerBody`）与数据结构解耦，将内置数组替换为接口返回的同构数据即可，无需改动渲染逻辑。

## 四、已知边界（演示口径，非缺陷）

1. 日期区间、编码搜索等均为前端内存筛选，未做分页；
2. "添加库存""新增"等操作不落库，刷新即还原；
3. 地块分摊的"末地块兜底"是为了演示口径严格对账，实际后端实现可用同样的兜底策略；
4. 农资的支取动作发生在小程序端，PC 页面只读展示支取流水。
