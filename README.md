# 征耘平台——农资管理、种植档案页面

| 文件                                   | 页面         | 使用角色                              |
| ------------------------------------ | ---------- | --------------------------------- |
| [`农资管理.html`](./stock.html) | 农资管理（出入库）  | 库管员（PC 端录入/入库）＋ 员工（小程序支取，页面展示其结果） |
| [`种植档案.html`](./planting_records.html)  | 种植档案（自动归档） | 归档后只读查看，面向全场角色                    |

## 一、农资管理页（[`农资管理.html`](./stock.html)）

### 1. 平台汇总卡片（页面顶部）

展示全平台口径：农资品类数、累计入库次数、累计支取次数、累计入库金额、累计支取金额、当前库存价值（Σ 库存量×单价）。

### 2. 搜索功能

添加按照农资编码搜索。

### 3. 新增功能优化

单价的库存单位，现在显示了计量单位和包装单位的并集，改为只显示2个值，即用户选中的计量单位和用户选中的包装单位，例如用户设置规格为：50公斤/袋，此时单价处的库存单位下拉列表的值应该只有公斤和袋。

### 4. 出入库记录

- 对全部农资进行出入库明细统计：
  -  搜索条件，包括农资名称、农资编码、农资类型、日期和出入库类型；
  -  导出功能，点击导出查看需要导出的字段；
  -  统计汇总：入库次数、出库次数、入库金额、出库金额；
  -  出入库明细，每新增或添加库存一次，产生一条入库记录，同理，小程序每进行一次农事处理且被通过时，产生出库记录，如果农事处理选择了多个农资则产生多条出库记录；
     -  按时间**降序**（最新在最上）；
     -  折叠态即显示 类型徽标、支取人、时间、数量×单价、金额（2位小数）；
     -  点击展开显示农事描述，该记录由小程序记录农事处理时产生；
     -  出库的记录需要显示分摊地块；
     -  展开支取记录后显示其选择的地块明细：地块名称、亩数、分摊支取数量、分摊支取金额；
     -  因地块较多，表格**竖向滚动**，表头吸顶、合计行吸底，长地块名自动换行。

- 对单条农资进行出入库明细统计：
  -  搜索条件，**只有日期和出入库类型**；
  -  导出功能，点击导出查看需要导出的字段；
  -  统计汇总：**入库数量、出库数量**、入库金额、出库金额；
  -  出入库明细，同上。

## 二、种植档案页（[`种植档案.html`](./planting_records.html) ）

### 1. 业务背景与归档规则

- 种植批次状态变为「**种植结束**」后，系统**自动生成档案**（无需人工创建），编号规则 `农场编号-年度-流水号`；
- 档案**固化**该批次的农艺方案执行过程与投入成本，**只读、可追溯**；
- 同一地块多次种植（复种）会生成多个批次档案。

### 2. 汇总卡片（页面顶部）

| 指标      | 口径                                   |
| ------- | ------------------------------------ |
| 已归档种植批次 | 档案条数（一次完整种植 = 1 个批次）                 |
| 归档总面积   | 各批次面积**直接相加**（复种的地块会被重复计入，是"累计种植面积"） |
| 涉及作物    | 批次涉及的作物去重数                           |
| 覆盖地块    | 批次涉及的地块按名称**去重**后的块数                 |
| 归档总投入成本 | 各批次投入成本之和                            |
| 综合亩均成本  | 总投入 ÷ 归档总面积                          |

> 归档批次 ≥ 覆盖地块：每块地只种过一次时两者相等；有复种时批次多于覆盖地块。

### 3. 档案列表

- **列**：档案编号 ｜ 地块（名称前带**地块形状图标**——青框渐变绿多边形，模拟地块轮廓，不同档案形状不同）｜ 种植信息（作物-品种标签）｜ 农艺方案 ｜ 面积 ｜ 种植时间 ｜ 结束时间 ｜ 生长周期(天) ｜ 农事完成度(x/y) ｜ 总投入成本 ｜ 亩均成本 ｜ 操作。
- **筛选**：种植物 ＋ 地块 ＋ 归档年度 ＋ 关键词（编码/方案/品种/地块模糊匹配）。
- 点击档案编号或"投入分析"打开详情抽屉。

### 4. 档案详情抽屉

顶部为档案头卡片：地块名(面积)、作物-品种、种植日期、种植方案、位置、结束时间（含生长周期天数与经手人）。下方两个 Tab：

#### Tab 1 农艺方案

- 复用地块管理页面-农艺方案；

#### Tab 2 投入分析

- 复用地块管理页面投入分析。
